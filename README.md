# Gandalf3 – דקדוק ומילים באנגלית 🧙

משחק לימוד אנגלית. רק דקדוק ומילים:

* בגרות 5 יחידות (רמה B2) – דקדוק, אוצר מילים לפי נושא, מילות קישור, פעלים חריגים, משפחות מילים
* תואר ראשון באנגלית – דקדוק אקדמי, מונחי בלשנות, מונחי ספרות, מילים של מאמר

כל החומר מגיע ממדריכי הלימוד שב-`c:\dev\docs\GANDALF\`.

## איך משחקים

* פותחים את `index.html` בדפדפן. לא צריך להתקין שום דבר.
* או מעלים ל-GitHub Pages ופותחים בטלפון (ראו `GITHUB_PAGES_SETUP.md`).
* הכוכבים נשמרים בדפדפן.
* בכל כניסה מחכה דמות אחרת מ"שר הטבעות" 🗺️
* במשחקי "פרק אחר פרק" ובמשחקי המילים כל שלב הוא נושא, ואפשר לבחור כל נושא. בשאר המשחקים כל שלב פותח את הבא.

## מבנה הקבצים

כל הקבצים בתיקייה הראשית (בלי תתי-תיקיות), כדי שיהיה קל להעלות:

```
Gandalf3/
├── index.html      # הדף הראשי
├── style.css       # עיצוב ואנימציות
├── english.css     # עיצוב המשחקים באנגלית
├── core.js         # צלילים, קונפטי, כוכבים, תפריטים, הדמות מארץ התיכונה
├── quiz.js         # מנוע החידונים ומנוע שאלות המילים
├── data.js         # המילים, הפעלים והמונחים (נוצר אוטומטית)
├── build_data.js   # בונה את data.js מתוך מדריכי GANDALF
├── grammar.js, ba_grammar.js   # שאלות דקדוק לפי נושא
├── vocab.js        # משחקי המילים לפי קבוצה
└── verbs.js, builder.js, families.js, match.js, scramble.js, speed.js   # משחק אחד בכל קובץ
```

## עדכון המילים

משנים את קבצי ה-`.txt` ב-`c:\dev\docs\GANDALF\` ומריצים:

```
node build_data.js
```

הסקריפט קורא שורות בצורה `english — עברית` ומייצר מחדש את `data.js`.

## הוספת שאלת דקדוק

ב-`grammar.js` וב-`ba_grammar.js` יש מערך `CHAPTERS`. כל שאלה היא `{ q, a, e }`:
`q` – המשפט, עם `___` במקום החסר. `a[0]` – תמיד התשובה הנכונה. `e` – ההסבר בעברית.
